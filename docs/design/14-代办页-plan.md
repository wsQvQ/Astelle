# 14 · 待办页（待办 / 计时）—— 功能与实施计划

> 10-11 用户拍板：双区清单底子；**不浪漫、标准理工命名**；要打勾消除 + 母子项。
> 预览：`docs/design/13-时光册-preview.html`（已按本计划更新）。
> ⚠️ 歧义待用户确认：「过去」区 = 计时器（已经 x 天）**还是** 已完成事项？
> 本计划按**计时器**做，打勾的沉入「已完成」折叠组；用户要后者就调。

## 1.5 布局结构（10-11 用户提出、双方定稿：**左右分屏 + 底部椭圆胶囊切换**）

- 不做上下长页：待办=动词（高频）/ 历时=名词（低频），生命周期不同，分开更冷静
- 底部胶囊 = **编辑/预览同款交互的圆头版**（ViewPill 血统：滑块动画/CenteredLineHeight
  全复用，圆角改 999dp、高度 46dp、带计数徽章「待办 3 · 历时 2」）
- **大标题随胶囊切换**（待办 ⇄ 历时），各自带 34→18sp 收缩；右上 ＋ 菜单随当前区排序
- 胶囊浮底居中，列表底部留白 ≥80dp 让位（同编辑器悬浮工具栏的让位口径）
- 记忆上次所在区（rememberSaveable），冷启动默认「待办」

## 1. 命名（10-11 用户定稿）

- 页面：**待办**（侧栏「计划」入口改造为本页；顶栏**同设置页语言**：返回圆钮常驻 +
  大标题上滑收缩 34→18sp + 柔洗底 + 发丝线，复用 SettingsScreen 那套）
- 区一：**待办**（可打勾、可带截止 = 倒计时）
- 区二：**历时**（已经 x 天的正计时器）——用户拍板，不再改
- 打勾归档：**已完成**（折叠组；用户确认打勾走这里）

## 2. 功能清单 v1

| # | 功能 | 细则 |
|---|---|---|
| 1 | 待办项 | 标题 · 可选截止日期 · 可选备注 · 无截止显示「—」 |
| 2 | 倒计时 | 截止日右侧「x 天」；=3 天 砖红；**当天 = 今天**；过期 = 已过 x 天（砖红） |
| 3 | **打勾消除** | 点描边圆圈 → 填充 Accent + 划线淡出（180ms）→ 滑入「已完成 n」折叠组；再点可撤销 |
| 4 | **母子项** | 一级母项 + N 个子项（缩进 + 竖线导引）；母项显示「x / n 已完成」；**子项全勾 ⇒ 母项自动勾**；母项勾 ⇒ 全部子项跟勾 |
| 5 | 计时项 | 标题 · 起始日期 · 大数字「已经 x 天」· 可置顶；**无勾选**（它是计时器不是任务） |
| 6 | 新建 | **右上角 ＋**（圆钮，同返回钮语言）→ 弹出菜单「新建待办 / 新建历时」→ 表单（标题 + 日期 + 父项可选） |
| 7 | 已完成折叠 | 默认收起，显示「已完成 · n」+ 划线残影；展开可撤销/删除 |
| 8 | 排序 | 待办按截止日升序（无截止沉底）；历时按天数降序；置顶优先——手动拖拽 v2 |
| 9 | 母项进度 | 标题下 2.5dp 细线（x/n）——视觉补充项 |

## 4. UI 实施（Compose，全部复用现有语言）

- 复选圈 = 描边圆（勾上 Accent 填充 + pop 一下，手感借 AstelleSwitch）
- 卡片 = 现有 SettingRow/Card 描边语言；天数 = 衬线大字（Type.kt 加一个 `NumeralStyle`）
- 打勾动画 = 划线 + alpha 淡出 + 滑入折叠组（animateItemPlacement）
- 分区小标 = 现有 SettingSection 语言（13sp Medium Accent）
