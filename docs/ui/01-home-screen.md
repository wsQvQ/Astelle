# 样式规划 — 首屏编辑器 + 侧边栏抽屉

> 学习对象：[Achilng/floral-notepaper](https://github.com/Achilng/floral-notepaper)（花笺）的设计语言
> 参考图：仅作「侧边栏滑出」交互参考，不参考其样式与功能
> 技术落点：Astelle Android · Jetpack Compose
> 状态：v2 样式规划稿，未实现

---

## 0. 产品骨架（已拍板）

**软件一打开就能写笔记。**

| 层级 | 是什么 | 何时出现 |
|---|---|---|
| **首屏 = 编辑器** | 全屏书写面，光标就位，立刻可打字 | 冷启动默认 |
| **侧边栏 = 抽屉** | 笔记索引（搜索 / 新建 / 分类 / 卡片列表） | 点顶栏侧栏按钮滑出，占屏 **约 4/5**（较 2/3 再加约 1/5），右侧 1/5 留编辑器+遮罩 |

启动流程：

```
冷启动
  └─► 编辑器（空白草稿，键盘收起，正文区可直接点按开写）
        │
        ├─ 点顶栏 [侧栏按钮] ──► 抽屉从左滑入（4/5 宽）
        │     ├─ 点某条笔记 ──► 关抽屉，编辑器载入该笔记
        │     ├─ 点「新建笔记」──► 关抽屉，开新空白笔记
        │     └─ 点遮罩/右滑 ──► 关抽屉，回到原文
        │
        └─ 直接打字 ──► 新草稿自动保存
```

> 决策记录：不再做「首页列表 + 底部 Tab」。列表降级为抽屉，首页让给书写。
> 这也解掉了此前「侧栏即主页 vs 底部 Tab」的分叉——两者都不对，**编辑器才是主页**。

## 1. 设计 Token

花笺原版色板见 `src/App.css` `@theme`（纸感米色 + 竹绿强调 + 低对比层级）。
Astelle 保留暖橙品牌，只借层级与用法：

| 角色 | Compose | 值 | 用法 |
|---|---|---|---|
| 纸底 | `Paper` | `#FAF5EF` | 主背景 |
| 次底 | `PaperWarm` | `#F3EBE0` | 按压/输入底/抽屉底 |
| 分割 | `Divider` | `#E8DDD0` | 1dp 线 |
| 主字 | `Ink` | `#2C2418` | 标题 |
| 次字 | `InkSoft` | `#4A4034` | 卡片标题 |
| 辅字 | `Muted` | `#9C8B74` | 摘要 |
| 淡字 | `Ghost` | `#B8A992` | 日期/字数/占位 |
| 强调 | `Accent` | `#D4843A` | 选中/主按钮（暖橙） |
| 强调底 | `AccentMist` | `#F7E8D4` | 选中卡片底 |
| 浮层 | `Surface` | `#FFFFFF` | 输入聚焦底 |
| 危险底 | `DangerBg` | `#FBEAEA` | 删除态 |

**字号**（手机 ×1.25）：页面标题 20sp / 卡片标题 15sp / 按钮正文 14sp / 摘要 13sp / 元信息 11sp mono。
**圆角**：输入按钮 10dp，卡片 14dp，色条 999dp。
**动效**：选中色条 600ms；分类折叠 250ms `cubic-bezier(0.22,1,0.36,1)`；抽屉滑入 280ms 同曲线；遮罩淡入 200ms。

## 2. 首屏 · 编辑器（冷启动默认）

一屏只干一件事：**写字**。左上角 = **新增笔记**，一点就开新稿。

### 2.0 新增笔记图标（左上角）

不画朴素的加号方框，用「带折角的稿纸 + ＋」：

```
  ╭─────────╮
  │        ╱│
  │      ·  │    稿纸轮廓 + 右上折角
  │    ＋   │    ＋ 靠右下，提示「再添一张」
  └─────────┘
```

- 触控 40×40，图标 22dp，描边 1.8dp `Accent`（这是全屏唯一常驻强调色图标，一眼能找到）。
- 按压：底 `AccentMist`，图标轻旋 8°。
- 点击 → 新空白笔记 + 轻提示「新建空白笔记」。

### 2.1 元素摆位 —— 定稿：方案 1「双层顶栏」

```
[≡] [⤺] [⤻]        [编辑|预览] [＋]
无标题                            ← 19sp，可点编辑
● 未保存 · 256 字 · 04-02 14:32   ← 11sp mono meta 行
─────────────────────────────
正文
```

**按钮顺序（已拍板）：侧栏在左，新建在右。**

| 位置 | 元素 | 规格 |
|---|---|---|
| 左 1 | **侧栏按钮** `≡` | 双栏面板图标，40dp 触控，`InkSoft` |
| 左 2-3 | 撤销 / 重做 | `Ghost`，无历史时 32% 透明禁用 |
| 右 2 | **预览切换** | 「编辑｜预览」两段滑块（见下） |
| 右 1 | **新增笔记** `＋` | `Accent` 描边图标（回滚至轻量版），40dp，按压 `AccentMist` 底 |
| 第二行 | 标题 | 19sp Medium，可点编辑，placeholder「无标题」 |
| 第三行 | meta | **日期 · 字数 · 保存**（左→右），11sp mono `Ghost`；右端 `⋯` 更多菜单 |

**保存胶囊（状态色语义）：**

| 状态 | 样式 |
|---|---|
| 未保存 | **灰框**：1dp `Divider` 描边、透明底、`Muted` 字、灰点 |
| 已保存 | **上色**：`AccentMist` 底、`#A86428` 字、橙点（品牌暖橙） |

点按胶囊可切换两种状态（原型可试）。

#### 预览按钮（学花笺 `SlidingButtonGroup`）

花笺在编辑器工具栏右端放「编辑｜分栏｜预览」三段滑块：药丸容器 `paper-warm/60` + 描边，白色高亮块在选项下 250ms `cubic-bezier(0.22,1,0.36,1)` 滑动，选中文字 `bamboo`（我们用 `Accent`）。

手机竖屏分栏没意义，收成 **「编辑｜预览」两段**：

- 容器圆角 10dp，padding 2dp，高约 28dp，整体约占 92dp 宽。
- 白色 `Surface` 高亮块滑动，选中 `Accent` Medium，未选 `Ghost`。
- 点「预览」→ 正文区渲染 Markdown（标题/引用/代码块），标题 meta 行保持可见。
- 点「编辑」→ 回到书写态，光标就位。

> 备选：若嫌滑块占宽，可换成单枚眼睛图标切换；但两段滑块能同时看见两种状态，更像花笺。

### 2.2 通用规格

- 顶栏行高 56dp，底边 1dp `Divider`；图标按钮 40dp 触控 / 20dp 图标。
- **按钮统一配色**：所有图标一律 `Muted`（#9C8B74 暖灰），**不因功能换色**；新建笔记靠 `AccentMist` 浅底强调，不靠换图标颜色。颜色只表达**状态**（选中/已保存）。
- 标题 placeholder「无标题」`Ghost`；正文 placeholder「写下你的想法…」+ 11sp「支持 Markdown」（开写即消失）。
- 正文 16sp / 行高 1.75 / 左右 padding 20dp。
- 字数、日期统一 11sp mono `tabular-nums` `Ghost`。

### 2.3 滚动行为

| 区域 | 滚动效果 |
|---|---|
| **编辑器正文** | 向下滚 > 12px：meta 行（日期/字数/保存）**收起淡出**；滚回顶部或回滚，它再落回。顶栏工具行始终钉住。 |
| **预览** | 同编辑器，meta 一并收起；正文内容自然滚动。 |
| **抽屉列表** | 搜索框钉顶；「Astelle」品牌头随列表向下滚**轻微上浮淡出**（不完全消失），制造深度。 |
| **抽屉打开** | 不带动编辑器滚动；遮罩独立。 |

设计意图：写字时信息栏让位给内容，状态性信息随时可扫但不抢戏。

> 原型：`index.html` 顶部可切换方案视图与侧边栏，「编辑｜预览」滑块可点。方案 1 为定稿。

## 3. 侧边栏 · 抽屉

上一版整屏样式**降级为抽屉内容**，组件规格不变；改两处：

1. **删掉顶栏那排**（App 名 + 搜索/设置两个小按钮）——抽屉不是主窗口，不需要标题栏；搜索本来就有搜索框，设置后置到编辑器 `⋯` 或抽屉底部。
2. **宽度改 4/5 屏**（约 288dp @360dp 宽），卡片在窄栏内自适应。

### 3.1 抽屉壳

| 项 | 规格 |
|---|---|
| 宽度 | 屏宽 × 4/5（下限 280dp，上限 380dp） |
| 底色 | `#EAE0D0` 深一档暖纸（和编辑器 `#FAF5EF` 拉开） |
| 卡片 | 纸色 `#FAF5EF` 浮起 + 1px 轻投影；选中 `#F7E8D4` + 橙投影 |
| 品牌字 | 头部标题 **Astelle**，衬线体 16sp SemiBold（纸感封面字） |
| **右缘 R 角** | **右上/右下圆角 20dp**（抽屉如一张浮起的纸卡） |
| 投影 | 右缘 `shadow-deep`（0 0 24dp rgba(44,36,24,0.12)） |
| 滑入 | 左→右 280ms `cubic-bezier(0.22,1,0.36,1)` |
| 遮罩 | 右侧 1/3 蒙 `Ink` 12% 透明度，点按关闭 |
| 关闭手势 | 点遮罩 / 向右滑抽屉 / 选中某条笔记后自动关 |

配色分层（从底到面）：`#EAE0D0` 抽屉底 → `#FAF5EF` 卡片/搜索 → `#FFFFFF` 聚焦浮层；强调 `#F7E8D4`。

### 3.2 抽屉内容（自上而下）

```
┌──────────────────────────┐
│ B. 搜索框                 │  40dp
├──────────────────────────┤
│ C. ＋新建笔记  /  导入     │  44+40dp
├──────────────────────────┤
│ D. 12 篇笔记      ＋分类   │  32dp
├──────────────────────────┤
│ E. 列表（滚动）           │  弹性
│    卡片 / 分类组 …        │
└──────────────────────────┘
```

**B. 搜索**：高 40dp，圆角 10dp，底 `Paper`（抽屉底是 warm，输入底用更亮的 Paper/Surface 区分），描边 1dp `Divider`；聚焦描边 `Accent` 30% + 底 `Surface`。放大镜 16dp，placeholder「搜索笔记…」。

**C. 操作**（v2 变更）：
- **「新建笔记」不再放进抽屉** —— 新增动作已升到首屏左上角，抽屉只做浏览/切换。
- 「导入 Markdown」通栏 38dp，`Muted` 字，按压变 `Accent`。保留在搜索框下方。
- 打开抽屉后看到的顺序：搜索 → 导入 → 筛选 chip（全部/置顶/收藏 + ＋分类）→ 列表。

**F. 底部入口坞（v3.2）**

抽屉下半截放功能入口；**点击 = 整页**。**无文字标签**，纯图标。

```
┌──────────────────────────┐
│ 列表滚动区                 │
│                           │
├──────────────────────────┤
│  (计划) (日记) (AI)      (设置) │
└──────────────────────────┘
```

| 入口 | 去向 | 图标（自绘 · 细节密度版） |
|---|---|---|
| **计划** | 计划整页 | 线圈台历：三枚装订环 + 日程点阵 + **打勾的一天** |
| **日记** | 日记整页 | 摊开内页：左页三道手写波纹、右页日期栏+两行、**书签带**垂在中缝 |
| **AI** | AI 整页 | **星群**：一大一中一小组星座 + 三粒星尘（Astelle 的星） |
| **设置** | 设置整页 | 螺母：外六边 + 倒角环 + 实心孔 + 六道滚花刻线 |

- 图标 18dp / 线宽 1.5 / 圆头，四枚细节密度对齐。

- ~~纪念~~ 已删除（v3.2）。
- 圆钮 **36dp**，图标 16dp `Muted`，无标签。
- **左组间距 12dp**（计划·日记·AI 抱紧）；设置 `margin-left:auto` 拉开大空档。不均分。
- 点击 → 抽屉关闭 → 整页从右滑入（300ms），左上返回。

**坞与列表的过渡：不用横线。** 列表底 72px 渐隐溶入坞区，坞带反向渐变上移 28px——接缝消失。

**侧栏滚动设计：**

| 层 | 行为 |
|---|---|
| 品牌头 Astelle | 随滚动上浮淡出（y×0.3，最多 18px，最低 20% 透明度） |
| 搜索框 | 始终钉顶；滚动后加浮起阴影 `elevated`（0 6px 18dp） |
| 筛选 chip / 导入 | 不滚动，固定在搜索下方 |
| 列表 | 自然滚动；**上下 22px 边缘渐隐**融入抽屉底色 |
| 分类组头 | **吸顶**（sticky + 毛玻璃），滚到下一组再被推走 |
| 入口坞 | 不动，始终锚在抽屉底部 |

手感目标：像翻一本有厚度的本子——页边柔和消失，章节标签停在眼前。

**D. 计数行**：`12 篇笔记` 11sp mono `Ghost`；右侧 `＋` 新建分类，点开内联输入条（「输入分类名…」），再点加号 = 提交。

**E. 卡片**（花笺原版规格）：
- 圆角 14dp，padding 12/10；默认透明 / 按压 `Paper` 70% / 选中 `AccentMist` 70%。
- 选中左缘色条 3×20dp `Accent` 60%，600ms 展开动画。
- 标题 15sp Medium `InkSoft`（选中 `Accent`）+ 日期 11sp mono `Ghost`。
- 摘要 2 行 13sp `Ghost`；底行 `14:32 · 256 字` 11sp mono。
- 空笔记摘要位 =「空白笔记」。
- **点卡片 → 关抽屉 → 编辑器载入**。

**分类组**：
- 组头 38dp 圆角 10dp：📁 + 名 13sp + 计数 11sp mono + 箭头；折叠底 `#FAF5EF`65%，展开底 `#F7E8D4`75%。
- 组内条目用**发丝分割线**（1px `#E8DDD0`）代替卡片投影，整组一色底、首尾圆角。
- 展开动画 250ms。组外卡片 = 未分类/收件箱。
- **长按组头** → 重命名 / 分享 / 删除。

**间距节奏（统一）**：卡片-卡片、卡片-文件夹、文件夹-文件夹一律 **3px**（margin 折叠后）；文件夹内部条目 0 间距，用发丝线分隔。

## 5. 还缺什么 + 可继续讨论

### 5.1 待做缺口

| # | 缺口 | 说明 | 建议 |
|---|---|---|---|
| 1 | **空状态** | 空草稿 / 空列表没有插画或引导语 | v1 必做 |
| 2 | **键盘工具条** | 键盘弹出后无加粗/标题/列表快捷条 | v1 强烈建议 |
| 3 | **长按菜单** | 卡片/分类的置顶·删除·移动 | v1 必做 |
| 4 | **删除确认** | 点删除无二次确认 | v1 必做 |
| 5 | **保存失败态** | 仅做了未保存/已保存 | v2 |
| 6 | **排序/视图密度** | 抽屉筛选 chip 只有全部/置顶/收藏 | v2 |
| 7 | **回收站 / 标签 / 设置页 / 深色模式 / 图片** | — | v2 |

### 5.2 值得再聊的优化

1. **滚动层次要不要再深一层？** 现在 meta 收起是「让位」；还可以做 iOS 大标题式——标题从 19sp 缩进顶栏。更高级，但写长标题时会跳。
2. **日期格式**：`04-02 14:32`（信息密度高）vs `4月2日`（更像日记）vs `周四`（近一周友好）。建议：7 天内显「昨天/周四」，更远显日期。
3. **字数实时更新**：打字时应跳动，而不是静态 256。
4. **新建笔记的入场**：新卡在抽屉里 600ms 上浮插入（花笺有 note-enter），增强「记下了」的反馈。
5. **触感反馈**：点新建、开抽屉、保存成功三处加轻 haptic。
6. **正文顶部渐隐**：内容滚到顶栏下方时加 8px 渐隐遮罩，避免文字贴线。
7. **抽屉遮罩模糊**：1/3 侧用 `backdrop-filter: blur(6px)` 代替纯色蒙层，深度感更强（iOS Sheet 风格）。
8. **标题/正文分割线**：只在标题非空时出现——要不要改成「聚焦标题时出现」？

已在原型落地：信息栏顺序、按钮统一、保存灰框/上色、meta 随滚动收起、抽屉品牌头浮动。

## 7. Compose 结构建议

```
ui/
  MainActivity.kt          // 壳：ModalNavigationDrawer 或自绘 AnimatedVisibility 抽屉
  editor/
    EditorScreen.kt        // 首屏：顶栏 + 正文
    EditorTopBar.kt        // [侧栏] 标题 [⋯]
  sidebar/
    SidebarDrawer.kt       // 抽屉壳 + 遮罩 + 手势
    SidebarContent.kt      // 组装 B/C/D/E
    SearchBar.kt
    NoteCard.kt
    CategoryGroup.kt
  theme/Color.kt           // 上表 token
```
