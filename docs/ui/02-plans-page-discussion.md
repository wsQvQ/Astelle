# 计划页 · 产品思路讨论稿

> 目的：先对齐「计划到底是什么」，再谈界面。Astelle 的底色是「随手收下，慢慢整理」——计划页不能变成重量级项目管理，否则和随记打架。

---

## 0. 你的三点，我怎么读

你这轮提了三样：

1. **倒计时**——离某个日子还有多久；
2. **过去多久**——离某个日子已经过了多久；
3. **最普通的待办**。

这三样刚好是同一件事的三个面：**一个有日期的日子 + 挂在时间上的行动**。

注意：v3 架构里我把「倒数/正数」拆成了独立的 **纪念页**。你这次把「过去多久」放回计划——**建议把纪念合并回计划**，理由：

- 正数和倒数是**同一种对象**（一个日子），只是相对今天的方向不同；
- 拆成两页后，「妈妈生日还有 58 天」和「搬家过去 128 天」会被切开，时间感反而碎了；
- 侧栏坞目前是「计划 · 日记 · AI · 设置」，本来就没有纪念的位置。

**一句话定调：计划 = 日子（倒数/正数）+ 待办（独立或挂在日子下）。** 纪念不单独成页，就是日子里的「往昔」那一半。

## 1. 计划页可能是什么？三条路线（回顾）

### 路线 A ·「倒数日」— 情感向

**核心物：一个日子。**

- 主视觉 = 最近一个倒计时的大数字
- 列表混合：倒数（将至）+ 正数（往昔）
- 每个日子可写几句打算，挂 1–2 条随记
- 气质参考：五年日记、倒数日 App、手帐胶带

**优点**：独一份的记忆点，温暖，和纸感美学同频。  
**缺点**：如果想管理「多步骤项目」，表达力不够。

### 路线 B ·「轻项目」— 目标向

**核心物：一个计划（有进度）。**

- 计划卡片：名称、进度、截止日
- 详情：里程碑、可勾选待办、关联随记
- 气质参考：Things 3 减重版、轻 Notion

**优点**：表达力强，真的能干活。  
**缺点**：容易越做越重，和「随手记」气质分裂。

### 路线 C ·「本周页」— 手帐向

**核心物：一周。**

- 上半：本周要做的事 + 倒计时标签
- 下半：未来几周的预告
- 气质参考：Bullet Journal weekly log

**优点**：时间感强。  
**缺点**：超过一周的事不好放。

---

## 2. 方向：A 为魂、B 为壳，正数一并收进来

**「日子」当门面，「待办」装行动，倒数与正数同框。**

### 2.1 数据模型（轻）

| 对象 | 字段 | 说明 |
|---|---|---|
| **日子** | 名称、日期 | 未来的产生「还有 N 天」，过去的产生「过去 N 天」 |
| | 重复 | 可选「每年」（生日/周年） |
| | 一句话打算 | 可选，一两句，不是正文 |
| | 分类色签 | 可选，考试/旅行/生活/工作 |
| **待办** | 文本、勾选 | 可独立，也可挂在某个日子下 |
| | 期限 | 可选：今天 / 这周 / 某日 / 无 |
| **关联** | 日子 ↔ 随记 | 可选，点进去就是笔记 |

进度**自动算**（勾了几条），不给用户拖进度条。

### 2.2 主界面结构

```
┌──────────────────────────┐
│ ‹ 计划                     │
│ ┌──────────────────────┐ │
│ │  还有 12 天            │ │  ← hero：最近的一个未来日子
│ │  毕业答辩              │ │
│ │  5月20 · 待办 3/8      │ │
│ └──────────────────────┘ │
│  今天要做                 │
│  ☐ PPT 改完              │
│  ☐ 约预答辩              │
│ ─────────────────────── │
│  日子                     │
│  还有 34 天   去杭州       │
│  还有 58 天   妈妈生日     │
│  ── 过去 ──              │
│  128 天前    搬到杭州     │
│  365 天前    答辩通过     │
│         （日子｜待办）     │  ← 底部大滑块，日记同款
└──────────────────────────┘
```

这样：倒计时有了、正数有了、待办有了，但没有甘特图、没有优先级矩阵、没有成员协作——不抢随记的戏。

- 不要让计划页变成第二个 Todoist。

## 4. 页面设计

### 4.1 原则（与日记页同一套语言）

- 返回钮：白底圆形浮钮；标题「计划」加粗 17px，**不显示年份**
- 底部居中**大滑块**：`日子 | 待办`，花笺 SlidingButtonGroup 同款，拇指 280ms
- 颜色只表达状态：未来 = Accent 数字，过去 = Muted 数字；勾选完成 = Accent 点
- 曲线 `cubic-bezier(.22,1,.36,1)`；**列表要克制**——一行两栏、细线分隔，不要色签堆满

### 4.2 三态

| 态 | 内容 | 进入 |
|---|---|---|
| **日子态** | hero 倒计时 + 日子列表（将至在上、往昔在下） | 默认 |
| **待办态** | 今天 / 本周 / 以后 分组清单，已完成折叠 | 滑块 |
| **详情态** | 大倒计时、要做的事、进度点、一句话打算 | 点列表项 |

> 减乱：日子态**不再塞「今天要做」**，待办只在待办态；列表不画分类色签。

### 4.3 新增流程（v1 原型已可点）

| 动作 | 怎么做 | 字段 |
|---|---|---|
| **加日子** | 右上角 `+` → 底部浅表单 | 名字、日期、可选「每年」；日期预览「还有 N 天 / N 天前」 |
| **改日子** | 列表长按 → 改日子 | 同上 |
| **删日子** | 列表长按 → 删除 | 即删 |
| **加待办（独立）** | 待办态顶部输入框，回车 | 一个字段，默认进「今天」 |
| **加待办（挂在日子）** | 详情态清单末行「添加一条…」回车 | 一个字段 |
| **勾掉** | 点圆圈 | 即完；已完成可展开回看 |
| **一句话打算** | 详情态输入框 | 一两句 |

原则：**字段能少则少**——名字+日期就能收下一个日子；待办只有一个输入框。要写的字越少，越符合「随手收下」。

### 4.4 视觉要点

1. **Hero**：AccentMist 浅底，`还有 12 天` 大字 + 名字 + 日期 meta，三行收束。
2. **日子列表**：左 mono 相对天数（未来 Accent / 过去 Muted），右名称，可选进度 `3/8`；细线分隔。
3. **将至 / 往昔**：一条细线 + 小字「过去」，不搞左右时间轴。
4. **待办态**：顶部毛玻璃快速添加条；分组「今天 / 本周 / 以后」；右侧可标所属日子（浅色）。
5. **详情态**：大倒计时 → 要做的事 → 一句话打算，自上而下。

### 4.5 空状态

- 没有日子：「还没有日子」+ 提示点右上角 `+`
- 今天没待办：「今天很轻」——不恐吓用户

## 5. 与导航的关系

侧栏底部坞：`[计划] [日记] [AI] … [设置]`——**纪念页取消**，正数活在计划的「往昔」区。

| 页 | 核心物 | 和随记的关系 |
|---|---|---|
| 随记（首页编辑器） | 自由收件箱 | 本体 |
| **计划** | 日子（倒数/正数）+ 待办 | 可关联随记 |
| **日记** | 一天一页 | 可从随记「收进日记」 |
| **设置** | 偏好 | — |

## 6. v1 范围建议

**一上来就做：** 倒数 + 正数 + 待办 + 进度 + 今天/本周聚合 + 底部滑块两态。

**v1 再顺手：** 重复日子、分类色签、一句话打算。

**先不做：** 提醒、关联随记、小组件、分享卡片——这些是加法，不影响主结构。
