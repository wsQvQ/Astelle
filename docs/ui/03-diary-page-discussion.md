# 日记页 · 产品思路讨论稿

> 目的：日记不是「第二本随记」。随记是自由收件箱（不定日子），日记是**一天一页**的回看与心情。先对齐它是哪种东西，再定界面。

---

## 0. 你的想法，我认同的三点

1. **热力图**——哪天写过一眼可见，是「坚持」的温柔可视化，不是打卡鞭子；
2. **点开即可写**——不设门槛，进入就是编辑器（和首页「一打开就写」同频）；
3. **心情落在热力图上**——情绪变成可回看的地图，日记就不只是文字。

方向没问题。下面只细化：主视图用什么粒度、心情怎么落格、两态怎么切换。

---

## 1. 日记页可能是什么？三条路线

### 路线 A ·「热力图地图」— 回看向（你的想法）

**核心物：一张日历地图 + 一天一页。**

```
   2026 年 4 月
   一 二 三 四 五 六 日
           ·  ·  ·  ·  1
   2  3  4  5  6  7  8     ← 格子深浅=写过，表情=那天的心情
   9 10 11 12 13 14 15
  ─────────────────────
  本月 12 天 · 连续 5 天
  点开任意一天开始写
```

- 上：月历热力图（主视觉）
- 点格子 → 进入该日书写页
- 心情以小表情/色点落在格子上
- 气质参考：Apple Health 心情、GitHub 热力图（暖化）、五年日记的日期感
- 适合：想看见「我这一年/这一月写过什么」的人

**优点**：有记忆点、有回看价值、和你预想一致。  
**缺点**：热力图偏「看」，最新一篇的书写入口要单独留一条。

### 路线 B ·「五年日记」— 横比向

**核心物：同一个日子的往年今日。**

```
  4月2日 · 周四
  ─────────────────
  2026   下午把设计稿又改了一遍……
  2025   （没写）
  2024   答辩通过，去吃了火锅
```

- 一页 = 月日固定槽位，按年填入
- 气质参考：五年日记本、Day One 的 On This Day

**优点**：翻旧账的浪漫，独一份。  
**缺点**：冷启动空得可怜；和「热力图回看」抢主视觉；一天只能一段。

### 路线 C ·「时间线」— 流向

**核心物：一串日子。**

```
  4月2日 · 周四      😊
  下午把设计稿又改了一遍……
  ─────────────────
  4月1日 · 周三      😐
  有点累，但推着走。
```

- 倒序列表，点进去改
- 气质参考：微博/日记 App 信息流

**优点**：实现最简单，最新内容永远在最上。  
**缺点**：没有「地图」的记忆点，和随记列表像。

## 2. 我的倾向：A 为魂（你的想法），年缩略当装饰

**日历热力图做门面，列表看标题，书写页装内容。**

```
┌──────────────────────────┐
│ ‹ 日记              2026  │
│   （ 日历 | 列表 ）        │  ← 滑块，与编辑|预览同款
│ ▪▫▪▫▫▪▫▫▫▫▪▫             │  ← 年缩略
│         四月        ‹ ›   │
│  一 二 三 四 五 六 日      │
│  …格子深浅=写过，表情=心情…│
│  这个月      12 篇 · 3,428 字│
│  ▓▓▓▓▓░░░░░  心情比例      │
│  😊5 · 🙂3 · 😐2 · 😢1 · 😠1│
│  连续 5 天 · 最长 12 天     │
│        [ 写今天 ]          │
└──────────────────────────┘
     ↓ 切到列表          ↓ 点格子
┌────────────────┐  ┌────────────────┐
│ 4月15日 周三  😊│  │ ‹ 4月15日 周三  │
│ 换灯的晚上      │  │                │
│ 下午把设计稿又…│  │ 换灯的晚上      │  ← 标题
│ ─────────────  │  │ 😊 🙂 😐 😢 😠 │
│ 4月14日 周二  🙂│  │ ─────────────  │
│ 又一版         │  │ 下午把设计稿又…│  ← 正文
└────────────────┘  │ 128 字         │
  看标题              └────────────────┘
```

| 组成 | 作用 |
|---|---|
| **月历热力图** | 主视觉：哪天写过、那天心情 |
| **日历\|列表滑块** | 热力图 / 标题列表，两段切换 |
| **月报** | 篇数、字数、心情比例、连续天数 |
| **书写页** | 标题 + 心情 chips + 正文 |
| **从随记收进日记** | 后期：随记可选「收进某天」 |

**不做的事**（v1）：心情排行榜、打卡连胜恐吓、必须先选心情才能写字、五年日记横比。

## 3. 心情怎么落在热力图上？

| 方案 | 样子 | 评价 |
|---|---|---|
| **A. 表情落在格子上** | 写过的日子：暖橙底 + 格心小 emoji | 最直观，和你预想一致 |
| B. 色块即心情 | 开心=橙、平静=米、低落=灰蓝… | 远看美，近看要记色表 |
| C. 只记有无 | 写过=深浅，不记心情 | 最干净，但丢了你说的「表情」 |

**建议 A，底色管「写没写」，表情管「心情」——两套编码，互不挤占。**

- 没写：`#F3EBE0` 空格
- 写了没心情：`AccentMist` 实底
- 写了有心情：`AccentMist` 实底 + 小表情
- 今天：`Accent` 细圈描边

心情 5 档：**开心 / 还行 / 平淡 / 难过 / 生气**。不选也能写。

## 4. 三态与切换

| 态 | 内容 | 进入 |
|---|---|---|
| **日历** | 年缩略 + 月历热力图 + 月报 | 默认 |
| **列表** | 瀑布卡片（标题 / 摘要 / 日期 / 心情） | 底部滑块切过去 |
| **书写** | 首页编辑器 + 心情 | 点格子 / 点卡片 / 写今天 |

**切换放页面底部居中**：浮动滑块 `日历 | 列表`（与「编辑｜预览」同款组件，两段 250ms）。

**列表 = 参差瀑布**：两列卡片、高度不齐，和随记收件箱的气质一致；不是等高一横一横。

**书写 = 首页编辑器同款**，只留必要元素：

```
‹  4月15日 · 周三
换灯的晚上            ← 标题 19sp
04-15 · 128 字        ← meta（不显示保存态）
😊 🙂 😐 😢 😠        ← 心情（新增）
────────────────
正文
```

去掉侧栏/撤销重做/编辑|预览/新建/⋯ 等按钮。

**标题**：可有可无；列表里优先显示标题，没写标题就用正文首行。

**月报（日历态）**：`12 篇 · 3,428 字` + 心情比例条 + 计数 + `连续 5 天 · 最长 12 天`。

---

## 5. 需要你拍板的三件事

1. **心情用 emoji、色点、还是色点+emoji？**（emoji 最像日记）
2. **月报还要不要别的？**（如「最近一篇标题」一行；不要就现在这套够用）
3. **v1 范围**：日历 + 列表 + 书写（标题/心情），还是连列表都砍掉只留日历？

我的建议：**1 emoji · 2 现在这套够了 · 3 三态都要（列表实现很轻）**。

---

## 6. 与随记的边界（防止做重）

| | 随记 | 日记 |
|---|---|---|
| 粒度 | 条（自由流） | 天（一天一页） |
| 时间 | 有时间戳就行 | 日期是主键 |
| 入口 | 一打开就是编辑器 | 坞 → 日历 → 点开写 |
| 结构 | 正文为主 | 标题 + 正文 + 心情 |
| 分类 | 文件夹/标签 | 没有分类，只有日期和心情 |
| 关系 | 可「收进日记」某天 | 不反向拆散随记 |

日记页从第一天起就长成**日历地图 + 一天一页**，不和随记抢「收件箱」的活。
