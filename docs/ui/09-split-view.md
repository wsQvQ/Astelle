# 09 · 花笺三栏（编辑 | 分栏 | 预览）（计划稿，未实现）

> 用户 2026-10-09 发花笺截图问「难不难」—— 不难，约一晚。本篇把一晚拆细。

## 1. 形态

- `EditorMode` 从 `Edit / Preview` 扩成 **`Edit / Split / Preview`** 三态
- **分栏只在大屏出现**（`isLargeScreen()` 同一把尺）；手机维持二态，切换器不挤
- Split 布局：`Row { 编辑区(weight 1f) │ 1dp Divider │ 预览区(weight 1f) }`
  - 预览栏顶部一个「预览」小标（花笺同款，Ghost 小字）
  - 两栏各自 `widthIn(max = 880.dp)` 居中 —— 沿用已拍板的正文限宽
  - 中缝 1dp `Divider` 发丝线，无填色（产品口径：边界靠描边）

## 2. 顶栏切换器

- 现在「编辑 | 预览」两段胶囊；大屏变「编辑 | 分栏 | 预览」三段
- 分栏段用居中图标或文字「分栏」—— 文字（和编辑/预览一致，别混语系）
- 切换**不重建编辑框**：`fieldValue` 住在 EditorScaffold 作用域，天然保活；
  ⚠️ 现状 Edit↔Preview 已是这个机制，Split 接同一个

## 3. 工具栏归属（关键细节）

- 分栏时格式工具栏**只服务编辑区**：悬浮在**编辑栏**底部，不是全宽横跨
- 对齐规则重审：大屏靠右的「右」改为「编辑栏的右」——分栏时编辑在左，
  工具栏跟着编辑栏走（右对齐于编辑栏内）
- 键盘弹起只推编辑区（预览栏不动）—— ime 内缩加在编辑栏一侧

## 4. 交互细节

- 预览栏沿用 `MarkdownBody(selectable = true)`（选中复制语义不变）
- 分栏下抽屉/侧栏照旧（常驻侧栏 + 分栏 = 三列，正是花笺那张图）
- 同步滚动：**v1 不做**（花笺也没做）；光标位置联动 v2 再议
- 导出画布不受影响（渲染共用 MarkdownBody，零改动）

## 5. 风格对齐（花笺感）

- 预览栏**无框无底**，靠中缝发丝线分界；栏内留白比编辑栏略大（呼吸感）
- 「预览」小标 11sp Ghost，和正文拉开层级
- 不加任何卡片阴影 —— 简约纪律

## 6. 实施清单（一晚）

1. `EditorMode.Split` + 切换器三段（大屏才显示第三段）
2. Split 布局分支（Row 双栏 + 中缝 + 限宽）
3. 工具栏挂编辑栏（对齐规则跟着栏走）
4. 真机：平板三态切换 ✓ / 手机二态不挤 ✓ / 旋转状态不丢 ✓ /
   常驻侧栏+分栏同屏 ✓ / 预览选中复制仍好使 ✓

## 7. 不做（v1）

- 两栏同步滚动、拖拽调栏宽、预览栏独立滚动条样式 —— 全部 v2
