# 05 · 视觉方向：从「暖到糊」到「暖而清」

> 这份是**提案**，不是已落地的改动。等你看过、点了头再动代码。
>
> 数字全部来自 `tools/palette-audit.py`，可以自己跑一遍：
> `python tools/palette-audit.py`

---

## 0. 一句话结论

**不是要换风格，是要"减"。**

现在这套暖纸色板的方向没错，问题是**暖得太均匀**：纸是暖的、墨也是暖的，
连"强调色的浅底"都是一个暖米色。全屏同一个色相、同一个明度区间，
眼睛找不到任何一个"确定"的东西 —— 这就是"不高级"的来源。

修法只有三条：

1. **墨改成中性**（纸保持暖）
2. **橙色的浓度和使用面积一起降下来**
3. **面收成明确的三层**，分割线要真的看得见

## 1. 先复盘：为什么我上次改完更丑了

你指的两件事，我照着改了：按钮不再顶出输入框（这个是对的），
文件夹底改成"和文章块一样的纸白"。

**问题出在第二件。** 数字对比：

| | 改之前 | 改之后 |
|---|---|---|
| 容器体 | `Paper @ 50%` 叠在抽屉底 → L*93.3 · **C=6.3** | `Paper` → L*96.8 · **C=3.5** |
| 组头 | `AccentMist @ 75%` → **C≈10** | 没动，**C≈10** |

也就是说：**组头那一块橙色的浓度一点没变，体却变得更白、更没色了。**
两者之间的色度落差反而拉到 ~6.5，"一条饱和橙带贴在一块纯白板上"的贴纸感更强了。

**我犯的错是：你指哪我打哪，却没有先问"组头这块橙色本身该不该存在"。**
真正该改的是组头（它太重了），而不是体。

## 2. 两个参考说的是同一件事

### 花笺 · floral-notepaper（你给的那个）

<https://github.com/Achilng/floral-notepaper>

| | 纸 | 主文字 |
|---|---|---|
| 色值 | `#f6f3ec` | `#1a1a18` |
| **色度 C** | 3.7 | **1.5** |

纸是暖的，**墨几乎是纯中性**。花笺的四个文字层级色度只有 `1.5 / 3.3 / 5.7 / 5.4`。

强调色是深绿 `#2d5a3d`（C=25.9），而它的浅底 `#e8f0eb` 只有 **C=3.8** ——
**浅底一直是"主色叠很淡的一层"（14.8%），不是一块实色。**

### granola.ai —— 同样"奶油纸 + 笔记"

（第三方提取的设计系统分析：[design-bites/granola.ai](https://github.com/educlopez/design-bites/blob/main/design-mds/granola.ai/DESIGN.md)）

| 角色 | 色值 | 备注 |
|---|---|---|
| 页面底 | `#f7f7f2` | 暖白纸 |
| 卡片 | `#ffffff` | 靠**温度差**浮起来 |
| 下沉区 | `#f2f2ec` | 微冷 |
| **主文字** | `#292929` | 文档原话：*"warm dark, **not cold black**"* |
| 次级 | `#72726e` | C≈4 |
| 三级 | `#acada8` | C≈5 |
| 强调浅底 | `#788c1526` | **alpha 15%** |

它的原文说：*"**No pure black… Don't use cool greys — every neutral should have warm undertones.**"*
——它用了**完全中性甚至微冷**的文字色（C≈0~5），只靠"不是纯黑"来保持温度。

**结论：两个成熟参考，主文字色度都是 0~6，我们的主文字是 9.6。**

## 3. 现在的问题（每一条都有数）

### 问题 1 · 墨太"棕"，和纸糊成一个色相

| 层级 | 花笺 C | 现在的 Astelle C | 倍数 |
|---|---|---|---|
| 主文字 | 1.5 | **9.6** | **6.5×** |
| 次文字 | 3.3 | 9.2 | 2.8× |
| 弱文字 | 5.7 | 14.9 | 2.6× |
| 最弱 | 5.4 | 13.9 | 2.6× |

更要命的是**色相**：

| | 纸的色相 | 墨的色相 |
|---|---|---|
| 花笺 | 90–93 | **109**（拉开了） |
| Astelle | 79–85 | **77–83**（和纸一样） |

暖纸 + 中性墨 = 印刷感、清爽。
暖纸 + 暖墨 = 一锅粥。

### 问题 2 · `AccentMist` 根本不是"橙的浅底"

| | 色相 | L* | C |
|---|---|---|---|
| `Paper` | 79.5 | 96.8 | 3.5 |
| `PaperWarm` | 82.4 | 93.4 | 6.3 |
| **`AccentMist`** | **80.9** | 92.7 | 11.7 |
| `Accent` | 64.3 | 62.3 | **56.8** |

`AccentMist` 的色相（80.9）和 `PaperWarm`（82.4）几乎一样，亮度也就差 0.7 ——
**它不是"橙的浅底"，它是"深一点的纸"。**

所以所有用 AccentMist 的地方（选中态、组头、保存胶囊）都不读作"品牌色"，
而是读作"这块背景颜色有点怪"。同时它浓度有主色的 20.6%，面积又铺得很大，
于是全屏都是说不清的米黄。

> 顺带纠正我自己一个想当然：**不能说"用 alpha 从主色推导，色相就准了"。**
> 低透明度时 Lab 色相本来就该被底色带偏，这是物理必然 —— `Accent @ 8%` 的色相
> 也是 76.8，并不比 `AccentMist` 更"橙"。
> 真正的差别在**浓度**（C 6.7 vs 11.7），以及 alpha 推导让颜色只有一个来源。

### 问题 3 · 橙太浓，而且铺得太大

- Accent `#D4843A` 的色度是 **56.8**；花笺的主色是 **25.9**（我们的 2.2 倍）
- 花笺的组头 = 主色叠 **8%**；我们的组头 = `AccentMist` 实色，**相当于叠 75%**

叠 75% 时色度是 42.8 —— 那不是"带一点温度"，那是**一块实心橙色**。

### 问题 4 · 分割线在抽屉底上是隐形的

`Divider #E8DDD0` 与 `DrawerBg #EAE0D0` 的亮度差只有 **dL\* = 0.9**。
低于 3 基本就是没画。

## 4. 提案色板

### 面 · 三层 + 一档发丝线

| 名 | 值 | L* | 用途 |
|---|---|---|---|
| `Canvas` | `#EDE6DB` | 91.6 | 抽屉底、页面底 |
| `Surface` | `#F9F5EF` | 96.7 | 卡片、分类容器、编辑器纸 |
| `Float` | `#FFFFFF` | 100.0 | 菜单、弹窗 |
| `Hairline` | `#DED4C5` | 85.3 | 分割线（对 Canvas 差 6.2，看得见）|

层次差：Canvas→Surface **5.1**，Surface→Float **3.3**，Canvas→Hairline **6.2** —— 全部合格。

### 墨 · 中性（色度 9.6/14.9 → 约 2/4）

| 名 | 值 | 对纸对比度 | 用途 |
|---|---|---|---|
| `Ink` | `#232320` | **14.5** | 标题、正文 |
| `InkSoft` | `#44443F` | **9.0** | 卡片标题、次级正文 |
| `Muted` | `#7E7C76` | 3.8 | 元信息（日期、字数）—— **不承载正文** |
| `Ghost` | `#AFADA6` | 2.1 | 占位符、禁用态 —— **不承载任何信息** |

> `Ghost` 对比度只有 2.1，这和两个参考一致（花笺 1.80 / granola ≈2.07）。
> 它只能用来放"没有也能读懂"的东西。

### 强调 · 一个橙，三种浓度

| 名 | 值 | 用途 |
|---|---|---|
| `Accent` | `#B4651B` | 品牌、当前选中指示、主操作（比现在的 `#D4843A` 深一档）|
| `AccentSoft` | `#E8A45C` | 按压态 |
| `AccentWash` | **`Accent @ 6–12%` 叠在 Surface 上** | 选中底、组头底 |
| `Danger` | `#A94242` | 仅删除 |

**`AccentWash` 刻意不给死色值** —— 用 alpha 从 `Accent` 推导。
理由不是"色相更准"（低透明度下它本来就会被底色带偏，见 §3 问题 2），
而是**颜色只有一个来源**：以后调主色，所有浅底自动跟着走，不会再有第二个
手挑的 `AccentMist` 悄悄漂到纸色上去。

## 5. 四条规矩

1. **颜色只表达状态。** 强调色不做装饰，工具栏图标一律安静。
2. **大面积浅底从主色用 alpha 叠出来，不要手挑十六进制。** 手挑的迟早漂成纸色
   （`AccentMist` 就是这么来的）。
3. **`Ghost` 不承载信息，`Muted` 不承载正文。** 拿不准就往上一级。
4. **层次靠背景温度差，不靠阴影。** 阴影只给真正的浮层（菜单 / 弹窗）。

## 6. 分类容器具体怎么改

这是你这次最不满的地方，单独说。

**组头**
- ❌ 不要实色橙底（现在 C≈10）
- ✅ 展开时 = `Accent @ 7%`（C≈6.5）+ 底部一条 `Hairline`
- ✅ 折叠时 = `Surface`，和卡片同色
- ✅ 图标 / 名字 `InkSoft`，计数 `Muted`
- ✅ 折叠 vs 展开的区分，靠**箭头旋转 + 内容高度 + 那 7% 的温度**

**容器体**
- ✅ `Surface`（上次已经改对，保留）
- ✅ 条目之间 `Hairline`
- ✅ 条目本身不成卡

**选中态**
- ❌ 不要整块 `AccentMist`（C=11.7，太浓）
- ✅ 3dp 左侧色条（`Accent`，这是最强的信号，交给它）
- ✅ 背景 `Accent @ 6%`
- ✅ 标题文字转 `Accent`

**为什么组头要淡到 7%**
看 `tools/palette-audit.py` 的第 [5] 项：

| 叠多少 | 结果色 | C |
|---|---|---|
| 6% | `#F5ECE2` | 6.1 |
| **8%** | `#F3E9DE` | 6.7 |
| 20% | `#EBD8C5` | 12.2 |
| 75%（现在）| — | **42.8** |

6~8% 是"这块带一点温度"；上了 20% 就是"一块橙色"。

## 7. 怎么验

```bash
python tools/palette-audit.py
```

它检查四件事，改色板之后跑一次：

1. 文字对比度（正文 ≥4.5，占位 ≥3.0）
2. 墨的色度（对着花笺 / granola 的 0~6 区间比）
3. 强调浅底的**浓度**（落在主色的 10~25% 才叫"带一点温度"）
4. 面与面的亮度差（<3 等于没分层）

**别只凭感觉吵。** 我的感觉上次就把事情改坏了。
