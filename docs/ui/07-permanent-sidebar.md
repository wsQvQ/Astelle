# 07 · 平板常驻侧栏（计划稿，未实现）

> 用户 2026-10-09：「该回合开始计划平板常驻侧栏（平板上好像可以不用侧边栏 R 角？
> 可以参考 floral-notepaper 的简约风格）」

## 1. 判定与形态

- **大屏尺**（和工具栏对齐同一把，已上线）：宽 > 高 且 ≥ 1100dp → 常驻侧栏
- 大屏：`PermanentNavigationDrawer` —— 侧栏一直可见，编辑区在右，**没有手势开关**
- 小屏/手机：**一切不变**（`ModalNavigationDrawer` + 全区域右滑，R 角、浮层、遮罩照旧）

## 2. 设计要点（按用户提示）

1. **常驻侧栏无 R 角**：齐边平直 —— 它是页面**结构**，不是弹出物。
   弹出式抽屉保留 R 角（浮层语义）。同一份 `DrawerSheet` 用 `permanent` 参数分支：
   常驻态 = 平直无圆角、右侧一道 1dp `Divider` 发丝线分界、无遮罩无阴影
2. **简约**（floral-notepaper）：⚠️ **歧义未清** —— floral-notepaper 具体是什么？
   （App？主题？信纸风格？）待用户给截图/链接后对着抄；先按「简约」理解：
   弱分隔、行高舒展、图标安静（`Muted`）、不堆填色块
3. 侧栏宽度固定 **300dp**（太宽挤压编辑区，太窄文件夹名列截断）
4. 大屏正文**限宽居中**（推荐最宽 ~720dp）：全宽一行字太长阅读累 —— ⚠️ **待拍板**

## 3. 实施清单（半天）

- 判定函数抽出来共用（工具栏 `largeScreen` 那把尺 → 一处定义，两处消费）
- `DrawerSheet(permanent: Boolean)`：R 角 / 遮罩 / 分界线三分支
- 布局二选一：`BoxWithConstraints` 或按配置分支 `PermanentNavigationDrawer` / `ModalNavigationDrawer`
- ⚠️ **状态不丢**：分支切换/旋转会重组子树 —— 编辑中的 `fieldValue` 依赖
  `remember{}`，要确认旋转不吞未落库的输入（去抖窗口内）；不行就 `rememberSaveable`
- 真机验证：平板横屏常驻 ✓ · 平板竖屏自动回抽屉 ✓ · 旋转/切换不丢字 ✓ ·
  点笔记切编辑区不动 ✓ · 工具栏自动靠右（已就位，回归确认）

## 4. 不做

- 侧栏可拖拽调宽（v2 再说）
- 侧栏折叠成图标条（空间够，不需要）
- 任何「智能隐藏」逻辑（常驻就是常驻，不跟用户玩躲猫猫）
