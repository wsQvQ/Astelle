> 状态：121 测绿，待用户验收（§6）。

## 1. 目标（验收定义）

1. 预测返回跟手时，露出的「返回后的页面」是**活的真页面**（会动、状态实时），不是照片
2. 松手落地零闪烁零跳变（真页面一直活着，压根没有"换页"这个动作）
3. **开页**转场也吃到红利：新页滑入时，下面的首页是活的（parallax 可以玩起来）
4. 顺手消灭快照的三个固有缺陷：导航时 `drawToBitmap` 拍摄卡一下 / 快照过期
   （主题切换、动态取色后不一致）/ RGB_565 色带

## 2. 为什么「最重」在我们这里反而更轻

| 成本项 | 快照方案（现状） | 真页面方案 |
|---|---|---|
| 导航时 | `drawToBitmap` 全窗截图 10-50ms 卡一下 | **0**（不拍了） |
| 手势中每帧 | 一次全屏位图 blit | 下层首页**静止不重绘**（组合树不变=零重组零重绘，只是图层合成） |
| 返回落地 | 照片→真页面有像素差风险 | **无换页动作**，天然零闪 |
| 内存 | 每层快照 10-20MB 位图 | 首页组合树常驻 ≈ 几 MB |

「重」的本意是**组合树大**（两页同时活着）——但代价只在**状态变化时**才付；
我们的首页是静态编辑器（开设置时键盘已收、光标已清），覆盖期间它什么都不干。
体量论据：全 app 4 个页面、1 个编辑器、无视频无地图，用户判断成立。

## 3. 架构手术（核心）

**现状**：NavHost 换页 —— 离开首页 = 首页组合被销毁，返回 = 重新组合（闪烁根源）。

**目标**：**首页永生，子页变浮层**：

```
Root Box {
    HomeRoute(...)                    // 永远组合着（状态零丢失：抽屉/滚动/编辑态）
    for (overlay in overlayStack) {   // Diary / Plans / Settings 依序叠上
        OverlayLayer(overlay) {       // 带自己的入/出场转场 + 预测返回跟手
            DiaryScreen / PlansScreen / SettingsScreen
        }
    }
}
```

- **数据结构**：`overlayStack: SnapshotStateList<AstelleDestination>`（就一个列表）
- **进**（抽屉点设置）= `overlayStack.add(Settings)` + 键盘收起；转场：右侧滑入盖上活首页
- **出**（返回键/手势/三键）= 弹栈；转场：离场页顺手势方向滑出，露出**一直活着**的首页
- **预测返回**：手势进度直接打在最上层浮层的 graphicsLayer 上——背后就是活首页，
  **现在的 PredictiveBackPage 逻辑整个保留，只删快照和拍摄**
- **首页根上的返回** = 系统默认（退出 app 的系统预览）不动
- **状态保活**：子页内 `SaveableStateProvider(key = route)` 保住子页滚动等状态
  （对齐现在 restoreState 的行为）；首页状态从此不可能丢（顺手把抽屉问题焊死）

### 转场手感（v1 参数，验收可调）

| 动作 | 效果 |
|---|---|
| 开页 | 浮层整幅**右侧滑入**（280ms FastOutSlowIn）+ 首页轻微左移 parallax（8%）+ 3% 压暗 |
| 返回 | 浮层右滑出（220ms）+ 首页回位；**方向与手势一致**，松手接力 |
| 预测返回跟手 | 浮层**1:1 跟手右移**（iOS 推卡感）+ 底部圆角 18dp + 首页跟手左移 parallax 12% |
| 取消 | 200ms spring 弹回 |

> 1:1 跟手是「效果最好」的关键升级：现在是缩 5%+移 24dp 的含蓄版，换成真推卡
> 配活首页，就是 RikkaHub/iOS 那个手感。嫌飘就换回含蓄版——一行参数的事。

## 4. 可行性评估

| 维度 | 判定 | 说明 |
|---|---|---|
| 技术 | ✅ 高 | 全部构件已验证过（graphicsLayer 跟手/转场/BackHandler 优先级/SaveableStateProvider）；navigation-compose 甚至可以整个退役（导航语义自管），零新依赖 |
| 性能 | ✅ 高 | 首页静止=零成本；手势=纯图层变换；比现状少一次截图+每帧 blit |
| 工作量 | 一晚 | AstelleNavHost 重写为 OverlayStack（~150 行）+ PredictiveBackPage 减法 + 抽屉接线微调 |
| 回归面 | 中 | 返回链路全动 → 验收清单重点盯；单测（121）纯业务层不受影响 |
| 风险 1 | IME/焦点 | 开浮层必须收键盘清焦点（现在开抽屉同款处理，照抄） |
| 风险 2 | 返回优先级 | 浮层 > 抽屉 > 系统 三层用 BackHandler 注册顺序排（已有成熟手法） |
| 风险 3 | 首页被盖时的无效绘制 | 覆盖期首页显示列表缓存=图层合成级别开销，可忽略；真在意可加 `alpha=0` 门（可选优化） |
